Package UI bindings own native work through the factory session signal and operation signals. Retirement can remove a session before asynchronous cleanup finishes, so shutdown must join tracked closing and factory promises. Preserve subscribe-before-snapshot ordering, pending-admission cancellation, and iterator cleanup when changing this lifecycle.

Full component preparation shares this inventory watcher and serialization barrier. Keep service admission ahead of generation-bound renderer admission. Publish status with the same inventory snapshot that was reconciled, not a fresh read. Missing public exports are activation errors, not evidence that a package has no component. Resolve exports inside the owning installed root.

Reconcile committed inventory before returning the service: a browser catalog query is not a startup barrier. CLI readiness requires a live owner process and lease renewal observed during that CLI call, not merely a recent persisted timestamp; retire its status before native cleanup, and let abrupt exit or stalled publication become pending rather than persisted ready.

Validate compiler linking under stock Node. Its CommonJS import namespaces include synthetic names such as `module.exports`; do not turn them into JavaScript identifiers or invent default exports for SDK modules.

Prepare server exports from a fresh relative-module bundle before Jiti evaluation. Async Jiti imports can retain Node's ESM cache despite `moduleCache: false`. Keep ordinary installed dependencies external and preserve the public entrypoint's resolution base.

Failed desired preparation must keep the active definition in reconciliation; an installed but broken candidate is not removal. Publish desired revision errors separately from runtime-confirmed active revisions, and keep that active renderer source loadable across browser refresh. Retirement and activation remain irreversible: creation, binding and migrations do not promise rollback.

Distribution defaults enter the real profile inventory through `seedDefaults` before package UI startup. Snapshot resolved dependencies/native builds into profile-owned immutable roots with own-name resolution links; flattened roots must not fall through to distribution dependencies on self imports. Record ordinary npm identities and keep completion markers under the inventory lock; removal must never reseed. Replace matching manifest names only after candidate validation. Persist names and derive component IDs from them so failed preparation retains the active generation across npm/local/Git replacements.

Renderer generations own utility CSS and inline worker bundles. Scan compiled renderer JavaScript, not shell `@source` paths; scope utilities to the named renderer's DOM boundaries, stopping at nested component boundaries. Global utilities override shell responsive rules; demoting them to a lower layer instead breaks component variants. Keep utility compilation free of global preflight resets. Worker imports use browser export conditions and must emit one self-contained script. Relative `new URL(..., import.meta.url)` assets cannot survive Blob loading; use supported inline worker imports instead.
