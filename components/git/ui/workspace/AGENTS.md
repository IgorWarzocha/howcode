- Keep compact summaries and detailed diff views on one bound capability. Compact-only presentation must not acquire patches; detail demand owns the stream and supplies summary stats without a second stats read.
- Directory, baseline and untracked-policy changes cancel the old binding and stream before exposing replacement data. Do not key the surrounding composer subtree to reset diff state: that also discards live composer and popover state. Resolved-baseline metadata, loading, errors, review and editing remain host-owned.
- Presentation-child lifetimes follow capability identity, not host callback identity. Use an Effect Event for navigation callbacks: aborting a child during React's external-store subscription commit exposes a closed snapshot. Never present an already-aborted capability.
- Detail placement and size changes must leave the detail subtree, source identity and demand mounted unchanged. Local Keep transforms, comments, editor drafts, collapsed files and hydration belong to that lifetime; CSS placement is not navigation or close. Persist layout separately from review data.
- Header dragging owns docking previews and undocking; resize handles own only geometry. Pointer previews must restore their styles and remove overlays on cancellation or unmount, and interactive header descendants must not start a drag. Git review controls stay inside the panel while the ordinary workspace composer remains operational.
